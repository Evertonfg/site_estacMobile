Política de Privacidade

Última atualização: [defina a data antes de publicar]

Esta Política de Privacidade descreve como a EstacMobile coleta, usa, armazena e protege dados pessoais de clientes, usuários da Plataforma e, quando aplicável, de motoristas cujos dados trafegam pelo sistema (ex.: placa, cartão de acesso), em conformidade com a Lei Geral de Proteção de Dados (Lei 13.709/2018 — LGPD).

1. Dados que coletamos

  • ▸ Dados de cadastro do Cliente: nome, e-mail, telefone, CNPJ/CPF, endereço do pátio.
  • ▸ Dados operacionais: placas de veículos, horários de entrada e saída, cartões de mensalista, valores cobrados.
  • ▸ Dados técnicos: endereço IP, logs de acesso ao sistema e ao aplicativo.
  • ▸ Dados de reconhecimento facial, quando essa funcionalidade é ativada pelo Cliente, mediante consentimento do motorista ou base legal aplicável definida pelo próprio Cliente enquanto operador do pátio.

2. Para que usamos os dados

Usamos os dados para viabilizar o funcionamento do sistema (liberar cancela, calcular cobrança, emitir relatórios), dar suporte técnico, cumprir obrigações legais e, quando autorizado, enviar comunicações sobre o produto.

3. Com quem compartilhamos

Não vendemos dados pessoais. Compartilhamos dados apenas com prestadores que operam a infraestrutura do serviço (hospedagem, processamento de pagamento, envio de mensagens) e quando exigido por lei ou ordem judicial.

4. Armazenamento e segurança

Os dados são armazenados em servidores com controles de acesso e criptografia adequados ao tipo de informação. Mesmo com essas medidas, nenhum sistema é 100% livre de risco, e qualquer incidente relevante será comunicado conforme exige a LGPD.

5. Seus direitos

Você pode solicitar confirmação de tratamento, acesso, correção, anonimização, portabilidade ou eliminação dos seus dados pessoais, além de informações sobre com quem compartilhamos esses dados, entrando em contato pelo canal abaixo.

6. Retenção dos dados

Mantemos os dados pelo tempo necessário para cumprir as finalidades descritas nesta Política e obrigações legais (fiscais, contratuais), sendo eliminados ou anonimizados após esse período, salvo exigência legal em contrário.

7. Contato do Encarregado (DPO)

Para exercer seus direitos ou tirar dúvidas sobre tratamento de dados, escreva para privacidade@estacmobile.com.br.

8. Alterações desta Política

Esta Política pode ser atualizada periodicamente. Mudanças relevantes serão comunicadas pelos mesmos canais usados para avisos importantes do produto.

Este texto é um modelo de referência e não substitui a revisão de um advogado antes da publicação — preencha os campos entre colchetes e ajuste conforme sua operação real (ex.: se usa reconhecimento facial, quem são os fornecedores de infraestrutura, etc.).
